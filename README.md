# High Performance Computing Projects

**Course:** University of Vienna (2025S)

This repository contains implementations of various high-performance computing projects focusing on parallel computing, distributed systems, and GPU acceleration.

## Projects

### [Project 1: Parallel 2D Heat Equation Solver](p1/README.md)

A high-performance parallel implementation of the 2D heat equation solver using the Jacobi iterative method, optimized for distributed-memory systems with hybrid MPI+OpenMP parallelization.

**Key Technologies:**
- MPI Cartesian Topology
- One-Sided Communication (MPI RMA)
- Hybrid MPI+OpenMP Parallelization
- Domain Decomposition

### [Project 3: GPU-Accelerated Savings Account System](p3/README.md)

A high-performance OpenCL implementation for computing cumulative savings account balances across multiple time periods, optimized for NVIDIA Tesla K20m GPUs.

**Key Technologies:**
- OpenCL
- GPU Acceleration
- Parallel Prefix Sum
- Memory Optimization
